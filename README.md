# Torneio de Truco AV 2026

Página do ranking final do torneio, publicada pelo GitHub Pages a partir de [`index.html`](./index.html).

## Estrutura

- `index.html` — estrutura e conteúdo estático da apresentação.
- `assets/css/style.css` — estilos, identidade visual e regras responsivas.
- `assets/js/app.js` — renderização do ranking, navegação dos slides e controles de teclado.
- `assets/js/ranking-data.js` — classificação e pontuações exibidas.

## Como executar

Abra `index.html` em um navegador. O projeto é estático e não requer instalação de dependências ou etapa de compilação. Para publicar, mantenha os caminhos relativos dos arquivos em `assets/`.

## Navegação

Use os botões na tela ou as teclas `←` e `→` para trocar de slide. Pressione `F` para alternar o modo de tela cheia.
